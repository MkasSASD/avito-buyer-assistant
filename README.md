# ИИ-помощник покупателя

Решение кейса хакатона ЮФУ 2026. Подбирает комплекты мебели и освещения
по запросу на естественном языке, уточняет недостающие условия и
соблюдает ограничения каталога.

## Установка

- Python 3.10+.
- Внешних зависимостей нет (только стандартная библиотека).
- Файл `run` должен быть исполняемым (в Linux: `chmod +x run`).

## Запуск

    ./run --catalog /absolute/path/catalog.json < request.json > response.json

## Переменные окружения

| Переменная | Назначение |
| --- | --- |
| `LLM_BASE_URL` | Базовый URL шлюза API (без `/chat/completions`). |
| `LLM_MODEL` | `google/gemma-4-31B-it`. |
| `LLM_API_KEY` | Индивидуальный ключ от организатора. |
| `LLM_USER_AGENT` | Имя клиента, например `hackathon-team-01/1.0`. |

## Где используется модель

`Gemma 4 31B` через API организаторов используется **только** в
`src/extractor.py` (`extract_requirements`) для извлечения из истории
диалога структурированных условий покупателя: города, бюджета, категорий
и ограничений характеристик.

Поиск, фильтрация, проверка бюджета, сборка комплектов и объяснения
выполняются кодом (`src/matcher.py`, `src/formatter.py`) по
структурированным полям каталога.

Описания объявлений в модель не передаются и не интерпретируются как
инструкции — это защищает от манипуляций через текст объявления.

## Локальная отладка без ключа

Установите `LLM_API_KEY=mock` — включится простая эвристика в
`src/llm_client.py::_mock_llm_extract`. Только для тестов, не для сдачи.

## Тесты

    LLM_API_KEY=mock LLM_BASE_URL=http://localhost python -m unittest test_pipeline -v

## Структура

    run                     исполняемая точка входа (bash → python)
    main.py                 обработка stdin/stdout, сборка ответа
    src/config.py           чтение env, логирование
    src/llm_client.py       HTTP-клиент API модели + мок
    src/extractor.py        промпт + JSON-схема для модели
    src/matcher.py          фильтрация и поиск комплектов
    src/formatter.py        форматы ok / clarify / no_match
    data/                   каталог, города, категории
    test_pipeline.py        smoke-тесты на моке
